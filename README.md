# SUPLEX — Baked.live player

Independent SUPLEX viewer following the public Spelunkr broadcast schedule. Video files are loaded from Internet Archive.

## Baked.live embed

Paste into Add → Custom Embed:

```html
<iframe src="https://buttocks.github.io/suplex-baked-player/" width="1280" height="720" frameborder="0" allow="autoplay; fullscreen; picture-in-picture" allowfullscreen></iframe>
```

## Enable GitHub Pages

Repository Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.

## Notes

The channel schedule is derived from the independently maintained [Spelunkr Guide](https://github.com/buddytohelpu/spelunkr-guide) broadcast client; this project is not affiliated with Spelunkr. Player playback is not synchronized by Baked.live itself. Browser autoplay and source availability can affect playback.
